# Screen Agent — Система мониторинга рабочего времени

## 📋 Что это?

Screen Agent — это корпоративная система для мониторинга активности сотрудников контактного центра. Система состоит из двух частей:

1. **Серверная часть** — веб-приложение для руководителей и администраторов
2. **Агент** — программа, которая устанавливается на компьютеры сотрудников

## 🎯 Возможности

### Для руководителей (Admin Panel):
- Просмотр статуса всех сотрудников в реальном времени
- Просмотр записей экрана и активности
- Статистика продуктивности за день/неделю/месяц
- Управление сотрудниками и их токенами доступа

### Для сотрудников (Agent):
- Автоматическая запись экрана в фоновом режиме
- Отслеживание активности (клики, нажатия клавиш)
- Минимальное влияние на производительность ПК
- Работает в системном трее (незаметно)

## 🚀 Быстрый старт

### Шаг 1: Развертывание сервера

**Требования:**
- Сервер с Ubuntu 22.04 или выше
- Минимум 4 GB RAM, 2 CPU
- Docker и Docker Compose установлены

**Установка:**

```bash
# Клонировать проект
git clone https://github.com/ShnaydermanK/Sreen-agent.git
cd Sreen-agent

# Запустить все сервисы
docker-compose up -d

# Применить миграции базы данных
docker-compose exec backend alembic upgrade head

# Загрузить тестовые данные
docker-compose exec backend python seed.py
```

**Проверка:**
- Откройте в браузере: `http://IP_СЕРВЕРА:5173`
- Войдите с учетными данными: `admin@screenagent.local` / `admin123`

### Шаг 2: Создание токена для сотрудника

1. Войдите в Admin Panel
2. Перейдите в раздел **Сотрудники**
3. Добавьте нового сотрудника
4. В карточке сотрудника создайте **Новый токен агента**
5. Скопируйте токен — он понадобится при установке агента

### Шаг 3: Установка агента на ПК сотрудника

**Вариант A: Установка через мастер (рекомендуется)**

1. Скачайте установщик: `Screen Agent Setup 1.0.0.exe` (из папки `agent/dist/`)
2. Запустите от имени администратора
3. Следуйте инструкциям мастера:
   - Введите адрес сервера: `http://IP_СЕРВЕРА:8000`
   - Вставьте токен агента из Admin Panel
4. Завершите установку

**Вариант B: Тихая установка (для массового развертывания)**

```bat
msiexec /i "Screen Agent-1.0.0.msi" /quiet /norestart ^
  SERVER_URL="http://192.168.1.100:8000" ^
  AGENT_TOKEN="ваш_токен_здесь"
```

### Шаг 4: Проверка работы

1. На ПК сотрудника в системном трее должна появиться иконка Screen Agent
2. Зеленая иконка = агент работает и ведет запись
3. В Admin Panel статус сотрудника должен измениться на **Online**
4. Через 1-2 минуты появятся первые записи экрана

## ⚙️ Сетевые сценарии

| Сценарий | Описание | Настройка агента |
|----------|----------|------------------|
| **Офис (LAN)** | Все ПК в одной локальной сети | `http://192.168.1.100:8000` |
| **Удаленка через VPN** | Сотрудники работают из дома | `http://192.168.1.100:8000` (через VPN) |
| **Облачный сервер** | Сервер на VPS (Yandex Cloud и т.д.) | `https://monitor.company.ru` |

**Важно:**
- Для работы через интернет обязательно настройте HTTPS (см. DEPLOYMENT.md, раздел 8)
- ПК сотрудников не обязательно должны быть в одной сети с сервером

## ❓ Решение проблем

| Проблема | Решение |
|----------|---------|
| Агент не подключается к серверу | Проверьте доступность IP сервера с ПК: `ping IP_СЕРВЕРА` |
| Статус агента не меняется на "online" | Проверьте токен в файле `C:\Program Files\Screen Agent\config.json` |
| Видео не записывается | Убедитесь, что на ПК установлен ffmpeg |
| Запись не воспроизводится | Проверьте работу Celery worker: `docker-compose logs celery_worker` |

**Логи агента:**
- Windows: `C:\Users\ИМЯ_ПОЛЬЗОВАТЕЛЯ\.screen-agent\agent.log`
- ПКМ на иконке в трее → "Показать лог"

## 🔒 Безопасность

**Перед использованием в продакшене:**

1. Смените пароли в `docker-compose.yml`:
   - `POSTGRES_PASSWORD`
   - `SECRET_KEY`
   - `MINIO_ROOT_PASSWORD`

2. Настройте HTTPS (обязательно при работе через интернет!)

3. Закройте порты в firewall сервера:
   ```bash
   ufw allow 22    # SSH
   ufw allow 443   # HTTPS
   ufw enable
   ```
