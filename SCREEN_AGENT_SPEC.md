## Обзор проекта

### Назначение

**Screen Agent** — корпоративная система мониторинга рабочего времени, состоящая из двух частей:

```
┌─────────────────────┐        ┌─────────────────────────┐
│   AGENT (на ПК)     │──────▶ │   ADMIN PANEL (web)     │
│                     │  sync  │                         │
│ · Запись экрана     │        │ · Просмотр записей      │
│ · Сжатие видео      │        │ · Аналитика активности  │
│ · Статистика        │        │ · Управление политиками │
│   активности        │        │ · Алерты и отчёты       │
└─────────────────────┘        └─────────────────────────┘
```

### Целевая аудитория

| Роль | Задача |
|------|--------|
| Оператор КЦ | Прозрачная фиксация рабочего времени |
| Супервизор | Контроль активности команды в реальном времени |
| WFM-аналитик | Статистика для расчёта реального AHT и продуктивности |
| IT-администратор | Деплой агентов, управление политиками |
| Руководство | Сводные отчёты эффективности |

### Ключевые принципы
- **Минимальная нагрузка на ПК** — агент потребляет < 5% CPU и < 200 МБ RAM
- **Офлайн-устойчивость** — запись ведётся при отсутствии сети, синхронизация при восстановлении
- **Прозрачность** — сотрудник уведомлён о факте записи (иконка в трее)
- **Соответствие законодательству** — обработка персональных данных по 152-ФЗ / GDPR

## Компонент 1 · Agent (клиентское приложение)

> Устанавливается на ПК каждого сотрудника КЦ.  
> Платформы: **Windows 10/11** (приоритет), macOS 12+ (опционально)

### A1 · Запись экрана

#### Режимы записи
- [ ] **Непрерывная запись** — запись всей рабочей смены без остановки
- [ ] **Запись по расписанию** — согласно графику из WFM (интеграция через API)
- [ ] **Запись по триггеру** — старт/стоп по событию (логин в CRM, начало звонка)
- [ ] **Выборочная запись** — случайные интервалы заданной длины (настраивается из админки)

#### Параметры захвата
- [ ] Захват основного монитора
- [ ] Захват всех мониторов одновременно (для рабочих мест с 2+ экранами)
- [ ] Раздельная запись каждого монитора в отдельный файл
- [ ] Настраиваемое разрешение записи: 1920×1080 / 1280×720 / масштаб (настраивается из политики)
- [ ] Настраиваемый FPS: 1 / 2 / 5 / 10 / 15 / 30 кадров в секунду
- [ ] Запись курсора мыши с подсветкой кликов
- [ ] Снимок экрана (screenshot) вместо видео — режим для минимальной нагрузки (1 кадр каждые N секунд)

#### Паузы в записи
- [ ] Автоматическая пауза при блокировке экрана (Windows Lock Screen)
- [ ] Автоматическая пауза при переходе в спящий режим
- [ ] Пауза при запуске приложений из списка исключений (настраивается политикой)
- [ ] Пауза по нажатию горячей клавиши (если разрешено политикой)
- [ ] Фиксация всех пауз с причиной в логе

### A2 · Сжатие и хранение видео

#### Кодеки и форматы
- [ ] **H.264 (AVC)** — основной кодек, аппаратное ускорение (NVENC, QuickSync, AMF)
- [ ] **H.265 (HEVC)** — режим максимального сжатия при поддержке оборудованием
- [ ] **AV1** — опциональный режим для новых ПК (лучшее соотношение качество/размер)
- [ ] Контейнер: **MP4** (основной), MKV (опциональный)
- [ ] Аудиозапись: опционально, кодек **AAC**, 64 кбит/с (микрофон рабочего места)

#### Настройки компрессии
- [ ] Режим CRF (Constant Rate Factor) — постоянное качество при переменном битрейте
  - Рекомендуемые значения: CRF 28–35 для записи экрана (баланс качество/размер)
- [ ] Режим CBR (Constant Bit Rate) — фиксированный размер файла в единицу времени
- [ ] Preset скорости кодирования: ultrafast / superfast / veryfast (настраивается)
- [ ] Keyframe interval: каждые 2–5 секунд (для быстрой перемотки)
- [ ] Профиль: Baseline / Main / High (зависит от ПК)

#### Ориентиры по размеру файлов

| Разрешение | FPS | Кодек | Размер за 8 ч |
|------------|-----|-------|---------------|
| 1920×1080 | 5 | H.264 CRF30 | ~500 МБ |
| 1920×1080 | 10 | H.264 CRF30 | ~900 МБ |
| 1280×720 | 5 | H.265 CRF32 | ~200 МБ |
| 1280×720 | 2 | H.265 CRF35 | ~80 МБ |
| Скриншоты | 1/30с | JPEG q70 | ~50 МБ |

#### Разбивка на сегменты
- [ ] Автоматическое разбиение записи на сегменты (настраиваемо: 15 / 30 / 60 мин)
- [ ] Причина: упрощение передачи, быстрый поиск нужного момента
- [ ] Каждый сегмент — самостоятельный MP4-файл с метаданными
- [ ] Метаданные сегмента: `employee_id`, `start_ts`, `end_ts`, `monitor_id`, `hostname`, `hash`

#### Локальный буфер
- [ ] Временное хранение на диске ПК до успешной загрузки на сервер
- [ ] Настраиваемый лимит локального буфера: 5 / 10 / 20 ГБ
- [ ] Автоматическое удаление локальных файлов после подтверждённой загрузки
- [ ] При переполнении буфера: удаление самых старых файлов или пауза записи (настраивается политикой)

### A3 · Сбор статистики активности

#### Активные приложения (Application Tracking)
- [ ] Имя исполняемого файла (`process name`)
- [ ] Заголовок активного окна (`window title`)
- [ ] Время старта фокуса на окне и время окончания
- [ ] Суммарное время в фокусе за день по каждому приложению
- [ ] Топ-N приложений по времени использования
- [ ] Категоризация приложений: CRM / Телефония / Браузер / Офис / Мессенджер / Прочее

> **Пример собираемых данных:**
> ```json
> {
>   "app": "chrome.exe",
>   "window_title": "Zendesk — Тикет #45231",
>   "category": "CRM",
>   "focus_start": "2026-05-22T09:15:30",
>   "focus_end": "2026-05-22T09:22:14",
>   "duration_sec": 404
> }
> ```

#### Активность пользователя (Activity Tracking)
- [ ] **Keyboard activity** — наличие нажатий клавиш (без записи содержимого — keylogger запрещён)
- [ ] **Mouse activity** — движения мыши, клики (количество, без координат в real-time)
- [ ] **Active / Idle** — автоматическое определение: нет ввода > N секунд = Idle
  - Настраиваемый порог: 30 / 60 / 120 / 300 секунд
- [ ] Суммарное активное время за смену
- [ ] Суммарное idle-время за смену
- [ ] Периоды idle с указанием длительности

#### Статусы рабочей сессии
- [ ] Время входа в Windows (login)
- [ ] Время выхода / завершения сессии (logout / shutdown)
- [ ] Блокировки экрана: время начала и конца
- [ ] Переходы в спящий режим
- [ ] Перезагрузки и аварийные завершения работы

#### Веб-активность (опционально, если разрешено политикой)
- [ ] Домены посещённых сайтов (без полного URL, без содержимого)
- [ ] Время на каждом домене
- [ ] Категория домена: рабочий / социальная сеть / развлечения / прочее
- [ ] Поддержка браузеров: Chrome, Firefox, Edge (через browser extension или API)

#### Телефонная активность (интеграция с softphone)
- [ ] Статус оператора: Ready / Busy / ACW / Break (из CTI/softphone API)
- [ ] Время начала/конца звонка
- [ ] Тип звонка: входящий / исходящий
- [ ] Длительность разговора и ACW

#### Скриншоты активного окна
- [ ] Периодические скриншоты активного окна (настраиваемый интервал: 1–10 мин)
- [ ] Привязка скриншота к временной метке и имени приложения
- [ ] Скриншоты хранятся отдельно от видеозаписи
- [ ] Сжатие: JPEG с настраиваемым качеством (q50–q85)

### A4 · Локальное хранилище и синхронизация

#### Структура локального хранилища
```
C:\ProgramData\ScreenAgent\
├── buffer\
│   ├── video\
│   │   ├── 2026-05-22_09-00-00_monitor1.mp4
│   │   └── 2026-05-22_09-30-00_monitor1.mp4
│   └── screenshots\
│       └── 2026-05-22_09-15-30.jpg
├── stats\
│   └── 2026-05-22.json          ← статистика за день
├── logs\
│   └── agent.log
└── config\
    └── policy.json               ← политика, полученная с сервера
```

#### Синхронизация с сервером
- [ ] Загрузка видеофайлов на сервер по завершении сегмента
- [ ] Загрузка статистики в реальном времени (каждые 60 секунд)
- [ ] Retry с экспоненциальным backoff при ошибках сети
- [ ] Возобновляемая загрузка (resumable upload) для больших файлов
- [ ] Верификация целостности: SHA-256 хэш файла до и после загрузки
- [ ] Очередь загрузки: приоритет статистики над видео

#### Офлайн-режим
- [ ] Полная функциональность записи и сбора статистики без сети
- [ ] Буферизация событий статистики в локальный SQLite
- [ ] Автоматическая синхронизация при восстановлении соединения
- [ ] Уведомление в трее о статусе синхронизации

### A5 · Фоновый режим и системная интеграция

#### Системный трей
- [ ] Иконка в трее с индикатором состояния: 🟢 запись / 🟡 пауза / 🔴 ошибка
- [ ] Тултип при наведении: текущий статус, время записи, размер буфера
- [ ] Контекстное меню (только разрешённые действия из политики):
  - Поставить запись на паузу (если разрешено)
  - Посмотреть свою статистику за сегодня
  - Статус синхронизации
  - Версия агента

#### Автозапуск и служба
- [ ] Запуск как Windows Service (фоновая служба, без UI-сессии)
- [ ] Автостарт при входе пользователя
- [ ] Защита от завершения процесса пользователем (watchdog)
- [ ] Автоматическое обновление агента через сервер (silent update)

#### Производительность
- [ ] Целевое потребление CPU: < 5% в фоне, < 15% во время кодирования
- [ ] Целевое потребление RAM: < 200 МБ
- [ ] Кодирование с низким приоритетом (`IDLE_PRIORITY_CLASS`)
- [ ] Аппаратное ускорение кодирования: NVENC (NVIDIA), QuickSync (Intel), AMF (AMD)
- [ ] Приостановка кодирования при нагрузке CPU > 80% (настраиваемый порог)

#### Установка и деплой
- [ ] MSI-инсталлятор для тихой установки (`msiexec /quiet`)
- [ ] Групповая политика AD (GPO) — деплой через SCCM / Intune
- [ ] Параметры установки через конфиг или командную строку: `server_url`, `org_token`
- [ ] Удаление только с правами администратора

### P5 · Управление политиками записи

#### Политика записи (Recording Policy)
Политика определяет правила работы агента и назначается на группы сотрудников.

- [ ] Создание / редактирование / удаление политик
- [ ] Назначение политики: на всю компанию / команду / отдельного сотрудника
- [ ] Приоритет при конфликте политик (индивидуальная > команда > компания)

#### Параметры политики
```yaml

## Безопасность и приватность

### Технические меры
- [ ] Транспорт: HTTPS / TLS 1.3 для всех соединений агент ↔ сервер
- [ ] Аутентификация агента: уникальный `agent_token` (UUID v4) на устройство
- [ ] Видеофайлы в хранилище: шифрование AES-256 (SSE)
- [ ] Доступ к записям: только через presigned URL с TTL (30 мин)
- [ ] Аудит-лог: каждый просмотр записи фиксируется (кто, когда, какой файл)
- [ ] RBAC: супервизор видит только свою команду, аналитик — только агрегаты без видео
- [ ] Агент **не** пишет содержимое клавиатуры — только факт нажатий

### Правовые аспекты
- [ ] Письменное уведомление сотрудника о факте мониторинга (при онбординге)
- [ ] Согласие на обработку персональных данных (152-ФЗ / GDPR)
- [ ] Политика хранения: видео удаляется через N дней (настраивается)
- [ ] Право сотрудника на ознакомление со своими данными
- [ ] Запрет передачи данных третьим лицам без согласия
- [ ] Документация о целях обработки данных

## Глоссарий

| Термин | Определение |
|--------|-------------|
| **Agent** | Клиентское приложение, работающее на ПК сотрудника |
| **Сегмент** | Видеофайл фиксированной длительности (часть смены) |
| **CRF** | Constant Rate Factor — параметр качества кодирования (меньше = лучше) |
| **HLS** | HTTP Live Streaming — протокол адаптивного видеостриминга |
| **NVENC** | Аппаратный видеокодировщик NVIDIA |
| **QuickSync** | Аппаратный видеокодировщик Intel |
| **AMF** | Аппаратный видеокодировщик AMD |
| **Idle** | Состояние отсутствия активности пользователя (нет клавиатуры/мыши) |
| **ACW** | After Call Work — работа после завершения звонка |
| **Presigned URL** | Временная ссылка с подписью для доступа к файлу в S3 |
| **SSE** | Server-Side Encryption — шифрование данных на стороне сервера |
| **RBAC** | Role-Based Access Control — разграничение доступа по ролям |
| **CTI** | Computer Telephony Integration — интеграция телефонии с ПК |
| **Watchdog** | Сторожевой процесс, перезапускающий агента при сбое |
| **Resumable upload** | Возобновляемая загрузка файла с прерванного места |
